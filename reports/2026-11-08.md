## 研究精选

### 1. VFlash：一次预测整段视觉轨迹

**一句话解释：** VFlash 为物理 AI 生成空间目标和运动计划，支持点、框和可变长度的轨迹。

**比喻讲解：** 一位领航员原本逐个念出经纬度。现在他先判断路线要画成什么形状，再把整条线一起画在地图上。轨迹坐标对应地图上同时落下的标记。

**核心方法：** 利用点、框和轨迹的结构，让轻量预测模块在一次前向计算中共同生成对应坐标。训练直接检查预测的空间结构。

**关键证据：** 作者报告，带 VFlash 规划的模型在四组 MolmoSpaces 任务中平均成功率为 70.2%，对照为 62.6%。

**学习启发：** 评估视觉规划可以同时检查坐标误差、生成耗时和最终操作成功率。

来源：[论文页面](https://huggingface.co/papers/2611.08449)。

### 2. TB-MathModel：检验 Agent 如何完成真实建模题

**一句话解释：** TB-MathModel 用 18 道真实竞赛题测试 Agent 能否理解资料、建模并交付可验证的结果。

**比喻讲解：** 考官交给考生一袋文件和一台电脑，考生要从图表里找数据、写程序计算，再填交答案表。评分系统先查答案是否满足题目条件，再看数值与参考解的差距。

**核心方法：** 在容器化终端提供原始题目与附件，要求提交结构化 JSON。用程序和 Lean 形式化约束检查可行性，再用多份优秀解作数值对照。

**关键证据：** 作者摘要报告，七种多模态参评配置中，最强配置的多参考 O-Eval 为 64.58%。这一指标对应本基准的数值评分。

**学习启发：** 设计数据分析 Agent 的评测时，可以让结果有固定输出格式，并给硬约束单独设检查项。

来源：[论文页面](https://huggingface.co/papers/2611.08237)；[官方代码](https://github.com/wxj630/terminal-bench-math-modeling)。

### 3. Coca-Cola：把工具输出压成决策所需的表示

**一句话解释：** Coca-Cola 让 Agent 用连续向量读取压缩后的工具观察，减少传给模型的内容。

**比喻讲解：** 办事员拿到一叠检索资料后，需要找出影响下一步选择的事实。助手把这些事实整理成小卡片。卡片对应压缩表示，整理的标准是办事员能否作出与读完整资料时相近的决定。

**核心方法：** 固定目标 Agent，训练压缩器，使 Agent 看到压缩观察时的下一步动作分布接近读取完整观察时的分布。

**关键证据：** 作者在四个网页搜索问答基准和两个模型系列上报告，总 token 消耗降低约 70%–89%，端到端用时降低约 24%–56%。

**学习启发：** 做工具输出压缩时，可以用任务表现和后续工具选择来评估压缩质量。

来源：[论文页面](https://huggingface.co/papers/2611.06500)；[官方代码](https://github.com/THU-Agent/Coca-cola)。
