## 研究精选

### 1. RLVB：证据还不足时，先继续看

**一句话解释：** RLVB 训练视觉语言 Agent 判断何时继续收集证据、何时作答。

**比喻讲解：** 侦探通过窗户观察案发现场，只看到部分线索。若仍有几个嫌疑人符合线索，继续调查通常比碰运气指认更可靠；模拟器在训练时充当知道标准答案与可见证据关系的教练。

**核心方法：** 训练用模拟器计算每一步答案的后验分布；当多个答案仍可能成立时奖励继续行动，证据足够时奖励作答，不依赖额外的评判模型。

**关键证据：** 作者报告，在三个视觉语言模型与三个基准共九种设置中，相对基础模型平均改善 17.1%；其中两个基准未用于训练。结果依论文的模拟环境与评测设置。

**学习启发：** 设计 Agent 奖励时，可把最终答案正确与证据是否充分区分开，但实际场景未必能获得精确后验。

来源：[论文页面](https://huggingface.co/papers/2611.32884)；[作者代码](https://github.com/declare-lab/RLVB)。

### 2. NightWatch：在操作间隙持续观察屏幕

**一句话解释：** NightWatch 用轻量观察模型帮助电脑操作 Agent 适应实时变化的界面。

**比喻讲解：** 操作员正在思考下一步时，旁边的助手持续关注下载进度和弹窗；界面发生变化时，操作员就不必只依赖几秒前的截图。

**核心方法：** 将 0.8B 观察模型与视觉语言 Agent 配合，流式监测界面状态，使决策与不断变化的环境同步。

**关键证据：** 作者报告在 OSWorld-Verified 中非推理耗时下降 33%、浪费时间下降 53%，任务成功率相当；在 DynaCU-Bench 中，大视觉语言 Agent 的成功率从 39.5% 升至 44.2%。结果限于论文比较的环境。

**学习启发：** 评估电脑操作 Agent 时，可以同时衡量截图是否过时、等待时间和最终成功率。

来源：[论文页面](https://huggingface.co/papers/2611.28947)。

### 3. ACAP：让机器人各部位并行工作

**一句话解释：** ACAP 将一台机器人的不同控制组交给多个持久编程 Agent 异步控制，由协调 Agent 管理依赖。

**比喻讲解：** 多位厨师分别负责切菜和调汁，独立工作可以同时进行；摆盘或共同搬运时，主厨再安排同步和分工。

**核心方法：** 成员 Agent 分别观察、推理、编写控制代码并执行；上层 Agent 分配任务、协调依赖，必要时直接控制多个部位。

**关键证据：** 作者报告 25 种任务与平台设置中的 72 次真实机器人试验，相对单 Agent 直接策略，按任务平衡的耗时降低 28.2%。结果取决于所测试的机器人和任务。

**学习启发：** 多 Agent 并行需要明确哪些动作独立、哪些存在物理依赖，并把协调成本纳入评测。

来源：[论文页面](https://huggingface.co/papers/2611.31205)；[项目页面](https://projects.zxhezexin.com/acap)。

### 4. SpecEngineeringBench：从需求出发寻找缺陷

**一句话解释：** 该基准考查编程 Agent 在没有明确问题位置提示时，能否生成测试并发现缺陷。

**比喻讲解：** 维修员只拿到设备应该如何工作的说明书，需要自己决定检查哪里、设计什么测试，再根据运行结果定位故障。

**核心方法：** 基准包括 78 个 Python 开源仓库的 100 个实例，分别评估测试套件生成和执行分析发现缺陷，并检查覆盖率和定位精度、召回率。

**关键证据：** 作者评测七个编程 Agent，报告测试在当前版本的通过率为 91.47%、变更相关覆盖率为 80.48%，而 Fail-to-Pass 率为 26.36%；文件级与函数级定位召回率分别为 78.11% 和 51.29%。

**学习启发：** 测试能运行、覆盖到代码，并不自动意味着测试能揭露缺陷，应分别评估。

来源：[论文页面](https://huggingface.co/papers/2611.32973)。

## 开源项目精选

### 5. mvanhorn/last30days-skill：整理近期多来源信息

**用途：** 该 Agent 技能围绕主题检索近期公开资料，并整理来自不同平台的线索。

**比喻讲解：** 研究助理分别翻阅社区讨论、新闻和项目记录，再把相关线索整理成一份简报；每条线索仍需要回到原始材料判断可信度。

**值得关注的功能：** README 描述了跨平台搜索、基于互动信号整理结果和生成摘要；不同来源的接入条件各异。

**使用门槛：** 需要支持 Agent Skills 的工具；部分来源可能需要额外配置、凭据或浏览器会话。项目功能在本次采集中未实际运行。

**建议：** 适合用来发现线索；重要结论应回查原始来源，避免把互动热度当作事实准确性的保证。

来源：[官方仓库](https://github.com/mvanhorn/last30days-skill)。
