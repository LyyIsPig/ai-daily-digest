## 研究精选

### 1. EgoUseBench：面对不断变化的第一人称场景

**一句话解释：** EgoUseBench 评测电脑操作 Agent 如何结合用户第一人称观察，在需求和环境改变时调整任务。

**比喻讲解：** 助理陪同用户采购，刚准备下单，用户发现商品不合适又改变要求。助理需要结合新画面和新要求，检查之前的操作是否仍然有效。

**核心方法：** 研究基于超过 74 小时真实第一人称录像构建 693 个任务，比较明确指令、离线场景观察和持续在线观察三种交互设置。

**关键证据：** 作者报告，所测模型在在线第一人称场景中的平均成功率比普通电脑操作设置低 26.3%；这是论文所测任务和模型下的差异。

**学习启发：** 测试助手时，不妨分别记录环境观察、用户要求与网页状态如何变化，避免仅检查最终页面。

来源：[论文页面](https://huggingface.co/papers/2611.34466)。

### 2. 让模型自己管理上下文

**一句话解释：** 论文比较外层系统自动压缩历史，与模型通过上下文 API 自行决定何时压缩。

**比喻讲解：** 工作桌装不下所有资料时，秘书可以按固定时间收拾；另一种办法是让研究员自己判断哪些笔记可以归档，同时保留接下来需要的材料。

**核心方法：** 在开源 Agent harness 中提供上下文 API，测试不同上下文预算下的文档研究和机器学习工程任务，并研究编辑后复用未改变部分的 KV 缓存。

**关键证据：** 作者报告，在 32K 预算的 OfficeQA Pro v2 上，GPT 6.1 从 21% 提升到 56%；缓存复用在所测条件下每次请求的预填充计算最多减少 15%。模型使用 API 的习惯差异较大。

**学习启发：** 设计长任务系统时，可分别衡量压缩决策质量、token 开销和推理引擎的缓存支持。

来源：[论文页面](https://huggingface.co/papers/2611.34147)。

### 3. Autoresearch Harness：怎样保存实验经验

**一句话解释：** 论文研究自主实验 Agent 的上下文管理和技能管理对长期任务表现的影响。

**比喻讲解：** 实验室保留每次试验可展开的记录，让后来者查具体条件；对于长期不用的经验手册，也要定期清理，避免重要内容被淹没。

**核心方法：** 在共同 Agent 框架内，对照近期截断基线，比较上下文折叠、滚动摘要及不同技能管理方法；组合上下文折叠和技能删除构建 MLEvolver。

**关键证据：** 作者报告上下文折叠在六组设置中均表现最佳，相对基线提升最高 19.2%；组合方法在 MLE-Bench Lite 获得 72.7% 奖牌率，在 KernelBench Level 3 的 fast_1 指标为 94%，均依论文预算和设置。

**学习启发：** 自主研究系统可保留可按需展开的实验记录，同时定期检视哪些经验真正被使用。

来源：[论文页面](https://huggingface.co/papers/2611.28244)。

### 4. ELITE：整合改进，而非每轮都评测候选

**一句话解释：** ELITE 探索在演化循环内不使用下游任务结果，能否改进编程 Agent。

**比喻讲解：** 几位工程师从同一个原型出发分别提出改造；集成人检查哪些零件互补、重复或冲突，再把兼容的设计合成一个新原型。

**核心方法：** 独立实现多项候选改进，分析实现机制并重新整合兼容部分；循环内仅使用确定性的结构和运行有效性检查，不以候选下游任务表现选拔。

**关键证据：** 作者报告，在 SWE-bench Pro 上最终 Agent 从 60.0% 升至 85.6%；同一论文中的 DGM 和 HGM 分别为 86.7% 和 88.3%。作者仍在演化后做下游测试，因此“免评测”只指演化循环内的候选选择。

**学习启发：** 当候选评测成本很高时，可以研究对改动机制做互补性和兼容性分析，但仍需独立测试最终结果。

来源：[论文页面](https://huggingface.co/papers/2611.21056)。

## 开源项目精选

### 5. google-labs-code/stitch-skills：为设计工作流提供技能

**用途：** 项目提供围绕 Google Stitch 的 Agent 技能和插件，覆盖设计、构建和辅助流程。

**比喻讲解：** 设计团队为不同工作准备不同手册：有人负责生成界面，有人整理设计系统，也有人将设计转换为组件。Agent 可以按任务调用对应流程。

**值得关注的功能：** README 列出界面生成、设计系统管理、从代码提取设计信息和组件转换等技能，并说明不同 Agent 环境的安装方式。

**使用门槛：** 使用这些技能需要配置 Stitch MCP；部分按需安装的技能存在依赖关系。具体功能在本次采集中未实测。

**建议：** 可先阅读所需技能的依赖和输入输出，再在练习项目中评估与现有设计流程的契合度。

来源：[官方仓库](https://github.com/google-labs-code/stitch-skills)。
