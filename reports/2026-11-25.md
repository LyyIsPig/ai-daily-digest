## 研究精选

### 1. Embo-Harness：给机器人策略设计更好的操作界面

**一句话解释：** Embo-Harness 系统研究多模态前沿模型作为机器人策略时，外层交互机制如何影响表现。

**比喻讲解：** 一位会看图的操作者要控制机械臂，除了自身判断能力，还取决于能否看清现场、用什么方式指示目标，以及工具能否准确执行。

**核心方法：** 作者分别研究提示、规划、动作执行和工具使用，比较动作表示、动作分块、视觉观察和策略细化等设计。

**关键证据：** 作者报告 RoboLab-120 成功率 83.3%，比其最强报告基线高 26.2 个百分点；四项真实操作任务的 20 次零样本试验中成功 15 次。结果限于论文的模型与任务设置。

**学习启发：** 评估具身 Agent 时，可把模型能力和观察、动作接口的设计分别做消融。

来源：[论文页面](https://huggingface.co/papers/2611.31201)。

### 2. Let the Fixer Decide：按修复器的需要定位代码

**一句话解释：** 用修复模型对候选代码位置的评分，训练一个更懂修复任务的定位器。

**比喻讲解：** 修理电器时，助手不应只找最终更换的零件，还要找能帮助维修师判断故障的线路图。维修师对候选资料的反馈可帮助助手下次找得更准。

**核心方法：** 定位器生成候选位置，冻结的修复器根据已验证补丁的似然给候选打分，再用加权监督微调训练定位器；这一评分过程不运行测试或强化学习。

**关键证据：** 作者报告基于 1629 条经测试验证的轨迹构建流程；在其设置中，定位器与教师定位找到故障的频率相当，读取代码减少 27.5%。开发集匹配对照中解决任务为 8 对 6，样本规模需结合论文理解。

**学习启发：** 代码检索的训练目标可以考虑下游修复器实际需要阅读的信息，而不只模仿最终修改文件。

来源：[论文页面](https://huggingface.co/papers/2611.12164)。

### 3. AutoPILOT：让实时游戏 Agent 不必每步都等待模型

**一句话解释：** AutoPILOT 在模型调用之间执行宏或闭环控制器，帮助视觉 Agent 应对不断运行的游戏。

**比喻讲解：** 司机不用每秒询问导航员才能转动方向盘；导航员给出动作方案后，控制器根据画面持续微调，遇到需要重新判断的情况再交回模型。

**核心方法：** 模型可选择单步动作、开环动作宏，或编写持续读取屏幕的闭环控制器；作者还构建包含 120 个浏览器游戏的 AFK-Bench。

**关键证据：** 摘要报告同等预算下，GPT-6.1 Sol 在实时游戏测试中的成功率由 VISTA 的 38.3% 提升至 68.6%；该比较依论文的游戏和预算设置。

**学习启发：** 实时 Agent 的性能不仅取决于模型，也取决于推理间隔内动作如何执行与反馈。

来源：[论文页面](https://huggingface.co/papers/2611.28202)。

### 4. SWE-Gym 数据审计：先检查奖励标签是否可靠

**一句话解释：** 研究审核编程 Agent 训练题的隐藏测试，识别正确补丁被错误判失败的情况。

**比喻讲解：** 如果标准答案本身有误，学生明明答对也会被扣分；先修正评分规则，再用这些题训练，学习信号才更可靠。

**核心方法：** 作者用两个模型家族发现可疑标签，并要求通过执行复现错误；随后修复或删除问题任务，发布含 1087 项审计任务的数据集。

**关键证据：** 摘要报告，9B 基础模型从未解决的任务中，74% 存在拒绝正确修复的测试；数据规模和难度匹配时，使用审计后任务训练的模型在 SWE-bench Verified 和 Pro 分别高 2.4 与 2.7 个百分点。

**学习启发：** 训练 Agent 时，应核对奖励的正确性，不能只根据任务通过率判断数据质量。

来源：[论文页面](https://huggingface.co/papers/2611.30207)；[作者代码与数据](https://github.com/Arist12/SWE-Gym-Verified)。

## 开源项目精选

### 5. Tracer-Cloud/opensre：协助定位 CI/CD 故障

**用途：** OpenSRE 是用于排查 CI/CD 可靠性问题的命令行 Agent，也提供生产故障调查的集成。

**比喻讲解：** 流水线报警后，助手先查运行日志和部署信息，提出可能的故障原因与修复，再交由工程师检查。

**值得关注的功能：** README 描述了读取失败运行、调查原因、提出修复，以及连接日志、指标和基础设施工具；这些是项目方的功能说明。

**使用门槛：** 项目处于公开 Alpha，接口和集成可能变化；可自托管并使用自己的模型，README 的首次启动流程也提供托管模型。许可证为 Apache-2.0。

**建议：** 可先在测试仓库验证诊断与权限边界，人工审核修改后再用于实际流水线。

来源：[官方仓库](https://github.com/Tracer-Cloud/opensre)。
