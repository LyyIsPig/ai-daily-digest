## 研究精选

### 1. SwarmEvolve：让多组 Agent 并行搜索程序解法

**一句话解释：** SwarmEvolve 用成组的 Agent 进行进化搜索，以较低的文本生成开销探索更多程序候选。

**比喻讲解：** 各个解题小组先画自己的草图，传递草图给组长，组长把不同思路拼成新方案。模型的内部缓存对应草图，筛选步骤负责留下差异较大的想法。

**核心方法：** 用隐藏状态距离筛选有差异的候选，通过 KV 缓存传递信息，由汇总 Agent 组合候选思路。

**关键证据：** 作者在 21 道数学发现和科学计算问题上报告，达到对照框架 60 分钟所获最高分的中位时间约为 3–8 分钟。

**学习启发：** 设计多 Agent 搜索时，可以同时记录候选多样性、通信耗时和达到目标分数所需时间。

来源：[论文页面](https://huggingface.co/papers/2611.08483)。

### 2. BestRand：用更稳的抽样估算模型全量评测成绩

**一句话解释：** BestRand 研究如何用更少的评测题估计完整基准表现，并减少抽样偶尔出现的大误差。

**比喻讲解：** 老师要了解学生在整本题库里的水平，却只能安排一次短测。先看若干份短卷的代表性，再挑选偏差更小的版本，类似 BestRand 对候选子集的筛选。

**核心方法：** 分析子集估计误差的分布，在保留随机抽样效率的同时降低大误差出现的风险。

**关键证据：** 作者报告，在 70 多个文本、多模态和 Agent 基准上，相比竞争方法，高误差风险和估计误差平均降低 50.2% 和 16.4%。

**学习启发：** 缩减回归题集时，可同时核对平均误差和大幅偏离全量结果的概率。

来源：[论文页面](https://huggingface.co/papers/2611.00883)；[官方代码](https://github.com/George-Ling3/BestRand)。

## 开源项目精选

### 3. anthropics/claude-quickstarts：从应用样例了解 Agent 接线方式

**用途：** 收集可作为 Claude API 应用起点的示例工程。

**比喻讲解：** 样板电路把输入、电源和输出都接好了。照着各个样例查看模型、工具和应用界面的连接方式，再替换自己的业务部件。

**值得关注的功能：** 仓库提供面向不同场景的独立示例，涵盖知识库客服、交互分析、桌面控制和浏览器操作。

**使用门槛：** 需要 Claude API Key，各目录有各自的运行依赖。仓库列出的许可证为 MIT。

**建议：** 想了解浏览器 Agent 如何组织工具调用时，可以从浏览器示例的工具定义和运行流程读起。

来源：[官方仓库](https://github.com/anthropics/claude-quickstarts)。

### 4. anthropics/skills：查看可复用的 Agent 技能样例

**用途：** 展示 Claude 如何把常见工作流程组织成可复用的技能。

**比喻讲解：** 接到不同工单时，助手从工具箱选出相应抽屉，拿到那项工作需要的操作顺序、工具和参考资料。每个独立技能目录对应一个抽屉。

**值得关注的功能：** 按技能目录提供 `SKILL.md` 和相关资源，覆盖网页测试、MCP 服务和文档处理等场景。

**使用门槛：** 运行条件取决于目标环境能否加载相应技能。复用前按目录核对依赖和许可。

**建议：** 可以对照两个技能目录，看看哪些规则写进说明，哪些可重复步骤交给脚本。

来源：[官方仓库](https://github.com/anthropics/skills)。

### 5. ranxianglei/billion-context：让长会话按需折叠和恢复上下文

**用途：** 在 Agent 与模型 API 的交互中管理长会话上下文，帮助保留可检索的历史。

**比喻讲解：** 文档越堆越多时，档案管理员把已处理的文件收起来，留下摘要和索引。需要确认细节时再取出原件。压缩、搜索和恢复对应这三个动作。

**值得关注的功能：** 项目说明介绍了代理式接入和各客户端的集成方式，模型可调用压缩、恢复、搜索与查看状态的工具。

**使用门槛：** 依赖受支持的客户端和接入配置。代理方式会处理发往模型的会话流量，使用前需了解接入边界。

**建议：** 如果在研究长会话记忆，可先看压缩范围如何记录，以及恢复时如何保持信息的对应关系。

来源：[官方仓库](https://github.com/ranxianglei/billion-context)。
