## 研究精选

### 1. Self-Improvement Memory：让优化器记得为什么改

**一句话解释：** SIM 为 harness 优化器保留历次改动的问题、理由、预测与实测结果，帮助它在环境变化时继续优化。

**比喻讲解：** 维修人员换零件后，如果只留下一台机器，下一位同事很难知道这次改动解决了什么问题。维护日志记录改动缘由和测试条件，使后来者能判断哪些经验仍适用。

**核心方法：** 将改动按反复出现的 harness 问题分组，记录预期、观察结果及评估上下文，并随新尝试扩展历史。

**关键证据：** 作者在四个领域、跨数据集及跨模型比较中报告 SIM 优于仅保留 harness 和仅保留根因的延续方式；十次编码源运行的配对实验中平均高 2.36 分。

**学习启发：** 优化 Agent 脚手架时，可把变更理由、测量条件和未达预期的结果作为一等记录。

来源：[论文页面](https://huggingface.co/papers/2611.18856)。

### 2. RepoFactory：把仓库变成可验证的训练环境

**一句话解释：** RepoFactory 将真实仓库转化为编码环境，并依据代理信号迭代改进环境的训练价值。

**比喻讲解：** 实训工坊以真实工程为蓝本，给学员任务和验收方法；课程设计者不只检查题目能否运行，还调整任务结构与工作范围。

**核心方法：** Environment Evolution Loop 使用有效性、结构耦合与实现范围构成的目标，通过代理反馈调整环境，让 Agent 从语言规格构建完整项目。

**关键证据：** 作者报告构建 17 个领域的 10,159 个环境；在指定模型与训练设置下，使用环境演化的模型在 NL2Repo-Bench 上提升 22.6 个百分点，而不使用环境演化为 17.5 个百分点。

**学习启发：** 训练环境本身可以成为优化对象，但代理信号仍需与下游表现核对。

来源：[论文页面](https://huggingface.co/papers/2611.21152)。

### 3. Agentic OPD：蒸馏可能改变工具使用习惯

**一句话解释：** 研究分析在策略蒸馏如何改变 Agent 的推理、动作与观察获取，并研究跨领域负迁移。

**比喻讲解：** 学徒学会一种工序后，可能在另一项工作中沿用不合适的步骤。选择性蒸馏像筛选哪些示范值得保留，同时要检查是否削弱原领域学习。

**核心方法：** 在数学、ALFWorld 和 τ²-bench 间比较交互模式；依据教师在领域强化学习前后的偏好变化筛选蒸馏位置。

**关键证据：** 作者报告，ALFWorld 监督使 τ²-bench 准确率从 41.5% 降到 6.6%；在另一选择性蒸馏比较中，保留 95% 位置使其由 11.5% 升至 29.9%，但存在源领域学习权衡。

**学习启发：** 给 Agent 加入专项能力时，应监测其他任务上的工具调用和依赖顺序，而非只看专项分数。

来源：[论文页面](https://huggingface.co/papers/2611.19244)。

### 4. 自主构造自改进过程：从目标到学习策略

**一句话解释：** 研究考查冻结的语言模型 Agent 是否能在获得基础资源和目标后，自行构造基于上下文的学习过程。

**比喻讲解：** 学生有课本、练习时间和提高成绩的目标，但老师不规定复习顺序；学生自行尝试、记录错误，并把有效笔记带到新题目。

**核心方法：** 在游戏环境中，Agent 获得有限计算预算及收集经验、更新文本的工具，自由实验，不预设外部学习循环。

**关键证据：** 作者观察到部分能力足够强的模型能够自我改进，其产生的文本材料在不同游戏时长、机制及 3D 导航评测中带来改进；结论限于论文测试条件。

**学习启发：** 评估自主学习时，应区分模型权重变化、上下文材料质量和跨任务迁移效果。

来源：[论文页面](https://huggingface.co/papers/2611.23219)。

## 开源项目精选

### 5. nmcbride-42/claude-code-guardrails：在命令执行前保护工作树

**用途：** 这是 Claude Code 的 PreToolUse hook，对部分破坏性 Git 操作先备份工作树，并阻止特定高风险命令。

**比喻讲解：** 施工队清理现场之前，管理员先把可恢复的材料备份；对某些无法恢复的操作，则直接关闭通道。备份和阻止分别对应两类规则。

**值得关注的功能：** README 描述了对脏工作树保存已跟踪改动和未跟踪文件，并对保护分支、敏感路径及部分远程操作设检查。

**使用门槛：** 需要 Claude Code hook 环境和 Git；规则覆盖依赖项目实际实现与配置，不能替代审阅和独立备份。安装前应检查脚本权限与备份位置。

**建议：** 可先在练习仓库测试预期命令的拦截和恢复，再考虑用于实际工作树。

来源：[官方仓库](https://github.com/nmcbride-42/claude-code-guardrails)。
