## 研究精选

### 1. MemOnce：让长对话记忆更紧凑

**一句话解释：** MemOnce 缓存紧凑的记忆表示，按输入需要检索并解码为注意力层使用的 KV 缓存。

**比喻讲解：** 图书馆不把每本书的所有章节摊在桌上，而是先保存索引卡；来新问题时挑出相关卡片，再把需要的资料展开。

**核心方法：** 只缓存部分最终层隐藏状态，并通过记忆编码器和解码器还原各层 KV；稀疏注意力在多层共享一次计算的检索索引。

**关键证据：** 摘要报告，将该方法适配 Qwen3.5-4B，在 100 万上下文设置下，记忆状态缓存缩小 1313 倍、预填充延迟降低 6.9 倍；结果限定于作者的模型与评测条件。论文发表于 11 月 20 日，11 月 23 日进入该榜。

**学习启发：** 做长期交互系统时，可分开考虑记忆存储、相关性检索和推理时还原的成本。

来源：[论文页面](https://huggingface.co/papers/2611.27973)。

### 2. Duopra：语音交流与任务执行一起训练

**一句话解释：** Duopra 在全双工语音交互中学习及时调用工具或向后台委派任务。

**比喻讲解：** 接线员既要听清客户中途补充的信息，也要把完整请求及时交给后台；如果派工漏掉关键条件，后台再能干也可能做错。

**核心方法：** 将后台视为接收自然语言请求的工具，结合协议监督微调、鼓励及时完整执行的强化学习，以及更新后的语音条件修复。

**关键证据：** 在作者的 Full-Duplex-Bench v3 流式设置中，使用同一后台时 Pass@1 从 4.7% 升至 44.7%；直接调用工具为 47.7%。这些是论文设置下的结果。论文发表于 11 月 19 日，11 月 23 日上榜。

**学习启发：** 评估语音 Agent 时，应把请求发起是否及时完整与后台执行是否正确分别衡量。

来源：[论文页面](https://huggingface.co/papers/2611.25773)；[作者代码](https://github.com/cyChen2003/duopra)。

### 3. ReSpaceBench：检查反复访问时的空间记忆

**一句话解释：** ReSpaceBench 评测模型能否辨认重访的物理空间并跟踪场景变化。

**比喻讲解：** 两间旅馆房间装饰很像，第二次来时其中一间还换了家具；记住“这是一间卧室”不等于认出具体是哪一间。

**核心方法：** 基准涵盖 590 个合成和真实住宅场景、3244 个问题及九项任务，包含相似房间干扰和跨次访问的物体变化。

**关键证据：** 作者测试 32 个模型和三个 Agent 视频理解框架；最强零样本模型总体准确率为 50.5%，在 450 题子集为 52.2%，同一子集人工标注者为 90.1%。测试中的 Agent 框架相对相同基础模型的直接推理总体没有提升。论文发表于 11 月 16 日，11 月 23 日上榜。

**学习启发：** 测试空间记忆时，应单独检查跨次访问的地点对应与变化追踪，而非只考察场景类别识别。

来源：[论文页面](https://huggingface.co/papers/2611.21485)。

## 开源项目精选

### 4. elementalsouls/Claude-BugHunter：整理安全研究技能

**用途：** 这是面向 Claude Code 的安全研究技能包，整理漏洞类别、研究流程与报告材料。

**比喻讲解：** 安全检查员面对不同设备时，需要不同清单和工具。项目将不同漏洞类别的检查思路放进对应抽屉，并提供整理证据和编写报告的流程。

**值得关注的功能：** README 描述了分类技能、公开披露案例模式、报告整理及 Burp MCP 集成；这些是项目功能说明，未在本次运行中实测。

**使用门槛：** 需要 Claude Code；部分集成功能需要额外工具或账户。实际测试应在获得授权的范围内进行。

**建议：** 可先阅读技能覆盖范围和证据整理方式，再根据自身场景评估是否使用。

来源：[官方仓库](https://github.com/elementalsouls/Claude-BugHunter)。

### 5. HKUDS/CLI-Anything：为软件构建命令行接口

**用途：** 项目探索为现有软件建立命令行接口，让 Agent 可以通过结构化命令使用其功能。

**比喻讲解：** 一台机器原本只供人在面板上操作；为它接上一组明确的按钮后，自动化程序也能按步骤发送指令并读取结果。

**值得关注的功能：** README 展示 CLI 生成、社区 CLI 汇集和以 JSON 或人类可读格式输出结果；具体支持范围取决于目标软件和对应接口。

**使用门槛：** 项目 README 标注 Python 3.10 及以上、Apache-2.0 许可证；目标软件本身及其运行环境仍需单独准备。

**建议：** 可以先挑一个熟悉的应用检查生成接口和测试结果，再评估自动化覆盖范围。

来源：[官方仓库](https://github.com/HKUDS/CLI-Anything)。
