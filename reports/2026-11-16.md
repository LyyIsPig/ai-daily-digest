## 研究精选

### 1. MixUA：让共享记忆知道该分享给谁

**一句话解释：** MixUA 把交互轨迹提炼成经验，并决定其属于特定用户与 Agent、用户、Agent 或全局范围。

**比喻讲解：** 一组维修人员可以共享某种工具的使用技巧，但客户的个人习惯应留在对应客户的工单中。记忆范围对应工单的访问范围，隐私探针则检查私人信息是否进入不该公开的区域。

**核心方法：** 系统从独立用户与 Agent 的轨迹中提取经验，按受益范围和可能泄露的信息分配作用域；CrossLearnBench 加入用户偏好和隐私探针。

**关键证据：** 作者报告，在五位用户、七个 Agent 的设置中，相对无记忆和单一全局记忆，成功率分别最多提高 16 和 5 个百分点；禁止范围中的隐私探针发现植入事实的比例最多为 0.02%。这不是对所有部署场景的隐私保证。

**学习启发：** 多租户记忆设计应同时评测共享收益、权限边界和泄漏风险。

来源：[论文页面](https://huggingface.co/papers/2611.10439)。

### 2. ACE-RL：训练 Agent 写好交接经验

**一句话解释：** ACE-RL 在固定执行框架中，让模型学习行动、总结经验和维护任务手册。

**比喻讲解：** 员工完成一次尝试后写下经验，管理员整理手册；下一位员工再用手册工作。手册是否有价值，要看它能不能帮助后续尝试，而不是只看文字是否漂亮。

**核心方法：** 以经验材料对后续 rollout 的影响评价手册修改，同时优化行动生成、反思和整理三个角色。

**关键证据：** 作者报告，在其测试的 Agent 基准中，该方法的留出集表现优于所比较的基线；作者还报告训练时每任务三次尝试，而优势延续到八次尝试的设置。

**学习启发：** 可以将经验质量与后续任务效果关联，单独评估“写记忆”和“使用记忆”的能力。

来源：[论文页面](https://huggingface.co/papers/2611.16409)。

## 开源项目精选

### 3. stablyai/orca：管理并行编程 Agent 工作区

**用途：** Orca 为多个编程 Agent 提供独立 worktree、聊天或终端界面与统一查看入口。

**比喻讲解：** 各工作室各自修改工程，协调员分配任务，再把差异交给负责人审阅。独立 worktree 对应独立工作室，diff 审阅对应验收台。

**值得关注的功能：** 官方 README 介绍了 Agent 编排、差异审阅、Git 集成及远程运行方式。

**使用门槛：** 项目提供 macOS、Windows 和 Linux 版本；选择远程或云环境时需自行配置相应运行环境。许可证为 MIT。

**建议：** 并行开发前先在练习仓库测试隔离与合并流程，再扩展到实际工程。

来源：[官方仓库](https://github.com/stablyai/orca)。

### 4. heygen-com/hyperframes：用 HTML 和 CSS 制作视频

**用途：** HyperFrames 将 HTML、CSS、媒体和可定位的动画渲染成 MP4，可配合编程 Agent 使用。

**比喻讲解：** 网页是舞台，CSS 与动画决定演员的位置和动作，渲染器按时间逐帧拍摄，最后剪成视频。

**值得关注的功能：** 提供命令行、Agent 技能和 Studio 等方式，适合以代码组织可重复渲染的动画。

**使用门槛：** README 标明 Node.js 22 或更新版本，许可证为 Apache-2.0；使用模型服务时应另行核对费用和权限。

**建议：** 先从短动画验证字体、布局和渲染效果，再用于较长视频。

来源：[官方仓库](https://github.com/heygen-com/hyperframes)。
