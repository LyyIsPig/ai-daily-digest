## 研究精选

### 1. SO-Arena：准确并不等于可靠

**一句话解释：** SO-Arena 评测快速结构化决策模型的能力范围、选项变化下的稳定性，以及无正确选项时能否识别缺失答案。

**比喻讲解：** 考生即使平均分很高，也可能在把选项顺序换一下时改变答案，或在题目没有正确答案时硬选一个。基准把这两种表现与普通答对率分开检查。

**核心方法：** 覆盖 11 个领域、五类能力，并通过人工核对标签与模型可见输入；模型还在沙箱中进行交互式执行。

**关键证据：** 作者对 21 个模型的评测发现，表现最好的 System One 模型在可靠性排名仅第七，说明总体准确率不能替代稳定性评估。

**学习启发：** 为路由或动作选择模型设评测时，应加入选项扰动与“无解”场景。

来源：[论文页面](https://huggingface.co/papers/2611.15777)；[官方代码](https://github.com/holdrain/SO-Arena)。

### 2. Decision Models：让判后果的模型教策略

**一句话解释：** 一些不擅长直接行动的决策模型，在看到完整轨迹后仍能有效评判步骤，为强化学习提供有用奖励。

**比喻讲解：** 行动者必须预判后果，复盘者却已经看见整局如何结束；因此复盘者能更好区分铺垫动作和看似容易却跑偏的动作。

**核心方法：** 比较决策模型与通用 LLM 作为 Actor、Judge 和 Teacher 的表现，以“这一步是否有帮助”而非“任务会否成功”评判动作。

**关键证据：** 作者报告，用 JEV 教师训练的 Qwen2.5-1.5B 在 ALFWorld 的成功率由 72.8% 升至 82.9%，WebShop 由 56.8% 升至 71.4%。

**学习启发：** 训练长程 Agent 时，可尝试从完整轨迹获得事后步骤评分，而非只用最终成败奖励。

来源：[论文页面](https://huggingface.co/papers/2611.17167)；[官方代码](https://github.com/ZJU-REAL/decision-agents)。

### 3. JustRUA：机器人 Agent 的关键可能在执行脚手架

**一句话解释：** JustRUA 在统一框架中逐项拆解机器人 Agent 的 harness、动作接口、经验复用和场景几何设计。

**比喻讲解：** 与其一次加十个增强模块，不如依次拔掉零件，确认到底是安全刹车、路线预览还是地图信息真正带来了提升。

**核心方法：** 从官方 L3 harness 出发，保留完整回合历史、提前停止运动，并研究经验和几何输入的独立作用。

**关键证据：** 作者报告，不用学习策略、自改进或任务微调时，简化 harness 将 RoboDojo 分数从 29.7 提升到 50.3；这是其特定模拟配置下的对照结果。

**学习启发：** 比较具身 Agent 时，应固定任务集和模型，单独消融 harness 设计，避免把多项改动混为模型能力。

来源：[论文页面](https://huggingface.co/papers/2611.16009)；[项目页面](https://zefanw.github.io/)。

### 4. DeepStress：检验 Agent 面对不可靠证据时是否谨慎

**一句话解释：** DeepStress 用可控的合成检索环境调节资料的可信度、相关性和真实性，压力测试深度检索 Agent。

**比喻讲解：** 研究员面对外观很像正规资料的错误文件，理想行为应是保留意见或继续核查，而不是自信地给出答案。系统把不同劣质资料比例当成可调旋钮。

**核心方法：** 以五类最终答案结果以及 RAS、CoPRAS 两个可靠性指标，兼顾谨慎行为和计算成本。

**关键证据：** 作者在 HotpotQA 与 BrowseComp-Plus 上评测 12 个系统，发现若来源存在明显可信度警示，一些开源 Agent 仍会自信回答；很多 HotpotQA 问题在资料全错时仍由参数知识作答。

**学习启发：** RAG 评测应区分“答案对”与“是否根据可靠证据答对”，并计量无依据的自信输出。

来源：[论文页面](https://huggingface.co/papers/2607.13920)。

### 5. HiVe-Mem：扩展关联，再按需拼装多模态证据

**一句话解释：** HiVe-Mem 用文本和视觉锚点构建关系图扩展记忆候选，再为每段记忆选择适合当前问题的证据形态。

**比喻讲解：** 先从一张档案卡找到相关文件夹，再根据问题只取所需的照片、摘要、原图或交互记录。横向扩展负责找全，纵向组合负责拿对。

**核心方法：** 关系图扩展语义检索种子；每段记忆保留摘要、描述、视觉视图、原图和历史，由轻量选择器独立组合。

**关键证据：** 作者在三个多模态记忆基准上报告，跨基础模型提升任务表现，并比最有效竞争基线减少约 90% token。

**学习启发：** 多模态记忆不宜只存一个压缩文本；应同时管理关联覆盖和每次回答需要的证据粒度。

来源：[论文页面](https://huggingface.co/papers/2611.12872)；[项目页面](https://viktoraxelsen.github.io/)。

### 6. Agent-R²：用真实工作文件训练交付导向 Agent

**一句话解释：** Agent-R² 从真实职业活动、网页工作流和公开附件中合成带多文件与细粒度量规的生产力任务。

**比喻讲解：** 助理训练不再面对模型编造的表格和文件，而是拿着真实报告、PDF 和电子表格，按一张验收清单交付成果。

**核心方法：** 从 10k 网页候选中筛得 4k 任务，配真实多格式附件和交付物量规，并以监督微调和基于量规的强化学习训练 4B 模型。

**关键证据：** 作者报告 Agent-R²-4B 在 GDPval 为 51.0%、OfficeQA 为 14.8%，高于所比较的 Qwen3-235B 结果；结论受训练数据、任务及评分设定限制。

**学习启发：** 提升办公 Agent 时，训练与评估都应包含真实文件环境、可验证交付物与明确量规。

来源：[论文页面](https://huggingface.co/papers/2611.08219)；[官方代码](https://github.com/ZJU-REAL/Agent-R2)。
