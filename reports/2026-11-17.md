## 研究精选

### 1. MIRIX-2.0：在事实与技能之间组织长期记忆

**一句话解释：** MIRIX-2.0 使用多种类型的记忆 Agent 管理事实和过程经验，并保留原始记录的来源。

**比喻讲解：** 不同档案员各管一种材料，原件仍放在档案柜里；索引将相关事件与事实关联，需要时能查回对应原件。后台整理员合并重复索引并提炼技能，而不改写原始档案。

**核心方法：** 六类记忆 Agent 保留完整记录，来源超图索引情节和语义记录；检索受预算约束，AutoDream 在写入路径之外合并重复锚点并提炼技能。

**关键证据：** 作者报告 LoCoMo 得分 91.4%、LongMemEval-S 为 72.6%，后者领先其最强对照 14.3 个百分点；MetaClaw-Bench 为 49.2%，对照技能库为 44.0%。结果依论文所用模型和预算。

**学习启发：** 记忆系统可以把原件保存、索引去重和技能提炼分开，方便追溯与回滚。

来源：[论文页面](https://huggingface.co/papers/2611.12068)；[项目页面](https://mirix.io/)。

### 2. WebArena-Pro：在多应用、多模态环境中考查网页 Agent

**一句话解释：** WebArena-Pro 用自托管网页应用评测 Agent 跨界面处理包含文本、图像、音频和视频的任务。

**比喻讲解：** 考生在一座模拟办公园区完成工单，每栋楼使用不同软件；有的线索在文字里，有的藏在录音或视频里。每次考试都重置环境，便于比较。

**核心方法：** 基准包括六个领域的 20 个应用、300 项任务，提供音视频信息提取动作与隔离、并行的任务执行环境；任务经人工验证。

**关键证据：** 作者报告，在所测配置中，Codex 搭配 GPT 6.1 Sol 和 Claude Code 搭配 Claude Opus 5.5 均达到 62.3%。该数值对应具体 Agent、模型与基准设置。

**学习启发：** 网页 Agent 评测应覆盖多种界面与模态，并保留可复现的应用状态。

来源：[论文页面](https://huggingface.co/papers/2611.17955)；[项目页面](https://webarena-pro.github.io/)。

### 3. VibePrevisBench：不只看视频，也检查场景

**一句话解释：** VibePrevisBench 评估编程 Agent 能否根据要求生成可执行 Blender 4D 场景及其代理视频。

**比喻讲解：** 一张房屋效果图可能看上去正确，内部结构却不符合图纸；评测一边重新运行代码检查场景事实，一边检查画面中能否识别这些事实。

**核心方法：** 242 项任务覆盖脚本、照片、续接和参考视频等输入；Scene Check 按规则检查场景，Screen Check 让视觉语言模型检查渲染画面。

**关键证据：** 作者分析 11 个前沿编程 Agent，发现它们会检查渲染结果，却常常无法纠正发现的错误；空间和镜头运动理解是区分因素。

**学习启发：** 自动生成视觉产物时，应分别验证底层结构和最终画面，并逐项对照需求。

来源：[论文页面](https://huggingface.co/papers/2611.15789)；[项目页面](https://vibeprevisbench.github.io/)。

## 开源项目精选

### 4. ag-ui-protocol/ag-ui：连接 Agent 和用户界面

**用途：** AG-UI 是基于事件的开放协议，用于将不同框架的 Agent 连接到面向用户的应用。

**比喻讲解：** 各种电器内部不同，但通用插头让它们能接入同一插座。协议中的类型化事件就是共同约定，让界面理解消息、状态和工具调用。

**值得关注的功能：** README 描述了双向事件流、流式消息、共享状态、人工介入和前端工具，并提供多语言 SDK。

**使用门槛：** 接入需要 Agent 端与客户端支持协议；示例提供 Python 和 TypeScript 路径。许可证为 MIT。

**建议：** 可先用简单聊天与共享状态示例理解事件顺序，再接入已有 Agent。

来源：[官方仓库](https://github.com/ag-ui-protocol/ag-ui)。

### 5. NVIDIA/SkillEvaluator：评估 Agent 技能是否有帮助

**用途：** SkillEvaluator 检查技能文件质量，并可比较 Agent 使用技能前后的任务表现。

**比喻讲解：** 审核培训手册时，先检查格式和内容，再让员工分别在有无手册的条件下完成相同任务，观察手册是否真的改善结果。

**值得关注的功能：** 项目提供分层质量检查、量规反馈和实际 Agent 运行评估，也提供 CI 集成入口。

**使用门槛：** README 列出 Python 3.12–3.14；静态检查与模型评估的依赖不同，模型评估可能需要服务凭证。许可证为 Apache-2.0。

**建议：** 先运行不依赖模型的静态检查，再针对真实任务设计有无技能的对照实验。

来源：[官方仓库](https://github.com/NVIDIA/SkillEvaluator)。
